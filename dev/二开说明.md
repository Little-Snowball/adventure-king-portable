# 便携版二开说明

## 参数传递

`launcher/launcher.cpp` 读取 `game.ini` 并通过 FlashVars 传给 `game/gameload.swf`（根影片加载时读取一次）：

| INI 字段 | FlashVar | 说明 |
|---|---|---|
| `[Game] ExperiencePerLevel` | `experiencePerLevel` | `0` 用原版曲线，`1..1000000` 统一每级经验，默认 `50`。 |
| `[Debug] Trace` | `debug` | `1` 输出 `[AdventureKing]` 日志到 `data/cache/log/ruffle.log`（或 `Play.exe --debug`）。 |

## 从源码重建

依赖：Python 3.11、JDK 17+、JPEXS FFDec 26.5.0、MinGW-w64 (x86)。

1. **构建启动器**：
   ```powershell
   i686-w64-mingw32-g++ -m32 -std=c++11 -O2 -s -static -static-libgcc -static-libstdc++ -municode -mwindows dev/launcher/launcher.cpp -o Play.exe -lshell32
   ```
2. **构建 `game/gameload.swf`**（仅改 `dev/swf/scripts` 时可直接以当前 `game/gameload.swf` 为输入）：
   ```powershell
   python dev/swf/build_loader.py --ffdec <ffdec.jar> --input game/gameload.swf --output game/gameload.swf
   ```
3. **构建 `game/game.swf`**（须按顺序从原版 `game.swf` 执行）：
   - `skills-input/PatchSkillInput.java`：双人长按技能连发
   - `python dev/pets/patch_pets.py --ffdec <ffdec.jar> --input <step1.swf> --output <step2.swf>`：满值注入与双人宠物预载
   - `python dev/invincible/patch_invincible.py --ffdec <ffdec.jar> --input <step2.swf> --output game/game.swf`：无敌旗标守卫与精灵耗蓝还原
   - 背包默认容量：`knapsack.Knapsack` 构造函数 `this.mCrtEquipCapacity = 25`（`d0 24 19 68 85 07`）改为 `60`（`0x3c`）

## 核心架构约定

- **无敌三层协作**：`game.swf` 在 `mainrole.changState` / `petrole.changState` 开头检查 `this.akInvincible`；因角色与宠物类为 sealed 类，宿主 `MainTimeline.applyFlag()` 将 `akInvincible` 写入 `mainrole.prototype` 与 `petrole.prototype`，由实例沿原型链读取。
- **进游戏时机**：`game.swf` 第 26 帧才初始化 `bigMapDealer` 与 `mainMenu`，`tryEnterGame()` 在 `ENTER_FRAME` 中轮询就绪后调用 `enterGame()`。
- **UI 宿主**：无敌开关（`game/ui/wudi-on.png`、`wudi-off.png`）挂载于 `Main.upLayer`，仅 `gameLevel >= 1` 显示；家园两按钮挂载于 `thisFight.uiLoader`，仅 `gameLevel == 0` 显示，使用后以会话标记隐藏。
- **宠物状态条**：`dropPetBoards()` 在 `myPet == null && roleCurPet == -1` 时从 `uiLoader` 移除 `petStaBoard1/2`。
- **数据规格**：角色上限 40、宠物上限 30（三阶 ID `10103`/`10203`/`10303`）；装备 `[id, 强化(5), 词条(5), 1]`，宝石 `2001..2005`；解锁关卡写 `mapArray = ["1".."13"]` 与非零 `scoreArray`。
