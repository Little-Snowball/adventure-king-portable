# 便携版二开说明

## 游戏参数

便携启动器将 `game.ini` 的值作为 FlashVars 传给 `game/gameload.swf`。载入根影片时读取一次，改动后需要重启。

| INI 字段 | FlashVar | 作用 |
|---|---|---|
| `[Game] Invincible` | `invincible` | `1` 在战士就绪时按帧补满 HP/MP。`0` 对战士使用原游戏生命与魔法规则。法师和精灵由游戏内补丁维持满值。 |
| `[Game] ExperiencePerLevel` | `experiencePerLevel` | `0` 使用原始经验曲线，`1` 至 `1000000` 将经验表的阈值统一设置。默认 `50`。每个关卡内每个角色应用一次。 |
| `[Debug] Trace` | `debug` | `1` 在启动、加载和应用经验值时输出 `[AdventureKing]` 日志。命令行 `Play.exe --debug` 也能临时启用。 |

窗口的尺寸、图形后端、主音量和全屏开关由启动器直接传给 Ruffle。日志位于 `data/cache/log/ruffle.log`。战士的按帧回血无法阻止同帧完成判定的致死事件。

新增数值时，可在 `launcher/launcher.cpp` 中增加 INI 读取和 FlashVar 参数，在 `swf/scripts` 中的 `MainTimeline.as` 的 `readSettings()` 添加读取，并将角色数值逻辑接到 `applySettings()`。测试战斗、菜单、退关时对象未初始化或被清除的情况。调试日志可沿用 `[AdventureKing]` 前缀。

## 从源码重建

开发用 Python 3.11、JDK 17 以上和 JPEXS FFDec 26.5.0。重建启动器还需要能生成 x86 Windows 程序的 MinGW-w64 C++ 编译器。

重建 SWF 补丁需要另行取得 7k7k 的原始 `gameload.swf` 和 `game.swf`，并放入自行准备的 `original` 目录。从试玩版根目录生成测试入口，验证后再替换 `game/gameload.swf`。

```powershell
python dev/swf/build_loader.py --ffdec D:/tools/ffdec/ffdec.jar --input original/gameload.swf --output patched-gameload.swf
```

用 x86 MinGW-w64 工具链重建启动器。使用支持 32 位目标的 x64 编译器时，改用对应编译器并保留 `-m32`。

```powershell
i686-w64-mingw32-g++ -m32 -std=c++11 -O2 -s -static -static-libgcc -static-libstdc++ -municode -mwindows dev/launcher/launcher.cpp -o Play.exe -lshell32
```

运行时通过固定的 `file:///AdventureKing/gameload.swf` 识别 SharedObject，通过真实本地资源目录解析关卡及音乐相对路径。保持该存档标识，可以在目录迁移后读取旧便携包存档。启动器启用了 Ruffle 的空 ExternalInterface 以支持原游戏启动时的两次 Cookie 查询，并通过私有运行设置关闭无须使用的 H.264 下载。

## 技能、精灵与预设存档

从 `original/game.swf` 重建游戏时，先用 `skills-input/PatchSkillInput.java` 修改两名玩家的技能输入，再用 `pets/patch_pets.py` 修改精灵逻辑。两个脚本每次需要不同的输入和输出路径，使用同一个 FFDec 26.5.0。此处的 Java 源文件执行要求 JDK 17 以上。技能连发沿用原动作与等级规则。法师和精灵在游戏的状态处理入口维持生命与能量的满值，装备变化时也会按新的上限更新。精灵的各形态同时取消技能的能量门槛和扣费。

`presets/build_presets.py` 生成可供编辑核对的 JSON 和游戏读入的 AMF3。改动生成器后运行它，再将两份 `.amf` 复制到 `game/presets`。游戏使用首次启动选择的预设来初始化对应的 SharedObject。个人进度仍使用原 `shengbingchuanqi`，预设分别用 `shengbingchuanqi-single-mage` 和 `shengbingchuanqi-double-mage`。恢复某份预设的初始进度时，可关闭游戏并将其对应的 `.sol` 移出 `data/saves`，下一次打开会从原始 `.amf` 载入。
