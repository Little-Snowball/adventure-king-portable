冒险王之神兵传奇 · Windows 便携版

开始游戏

在可写目录中双击 Play.exe。保留 game、runtime 和 game.ini 的相对位置。游戏会在独立窗口打开，可断网游玩，无需安装浏览器、Flash 插件或运行库。

在启动选单选择「新开游戏 · 单人」或「新开游戏 · 双人」可直接创建角色。通过「游戏主菜单」可以继续个人进度或修改按键。剧情可以跳过。玩家一默认 A/D 移动，W 与出口或 NPC 互动，J 普通攻击，K 跳跃。

两位玩家都可以长按常用技能键和快捷技能键连续释放，动作冷却与解锁条件沿用原游戏规则。例如法师达到 20 级后，玩家一可长按 4 连放星轮，玩家二默认用数字键盘 +。法师和精灵的生命与能量始终保持满值，受到攻击和释放技能时也保持满格。

存档

启动选单中的两份预设可直接进入村庄。第一份为第三款粉发女法师「星铃」。第二份为第三款男法师「墨羽」和第三款粉发女法师「星铃」。装备头盔时会遮住发型，可以在背包中摘下查看。每位角色均为 40 级，拥有 25 件法师及通用盾高级装备、五种各 99 颗宝石，以及三只三阶 30 级精灵。两份预设都已开放并记录全部 13 关通关。

三套进度各自保存。游戏在原有的关卡结算或出村等提交点保存，退出后可将 data\saves 随游戏目录复制。两份预设的可写副本在首次打开时创建，初始文件保存在 game\presets。此版的存档和原浏览器版的本地存储分开。

调试与设置

关闭游戏后，用记事本编辑 game.ini，保存后重新启动。开关值 1 为开、0 为关。

  [Game]
  Invincible=1             开启战士按帧补满生命和魔法的机制
  ExperiencePerLevel=50    每级所需经验，0 使用原版经验曲线，允许 0 至 1000000

  [Window]
  Width=960                初始窗口宽度，允许 480 至 3840
  Height=600               初始窗口高度，允许 300 至 2160
  Fullscreen=0             启动时进入全屏
  Volume=100               播放器主音量，允许 0 至 100
  Graphics=auto            可选 auto、dx12、vulkan、gl。出现图形错误时可切换后端

  [Debug]
  Trace=0                  设为 1 记录配置与经验应用事件，也可运行 Play.exe --debug

日志在 data\cache\log\ruffle.log。调试行以 [AdventureKing] 开头。保留同一目录的一份运行实例，避免覆盖存档。dev 目录包含源码、构建说明和资源校验清单。

运行环境

Windows 10/11 普通桌面版。64 位 Intel/AMD Windows 自动使用 x64 播放器，32 位 Windows 使用 x86，ARM64 通过 Windows 的 x86 模拟运行。图形由 Ruffle 自动选择可用后端，仍需系统有可用的图形驱动或软件适配器。S 模式和受组织限制的设备可能禁止启动外部 EXE。

本包在 Windows 11 x64 环境验证。同一环境下，32 位播放器使用 auto 可运行，强制 dx12 时该显卡驱动出现着色器错误。Win10 和 ARM64 的实机兼容性仍需实机验证。

源游戏为 7k7k 的「冒险王之神兵传奇幸运无敌版」。包内 Ruffle 版本为 nightly-2026-11-20，许可证在 runtime 的相应目录。
